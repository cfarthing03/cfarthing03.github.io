world.html:
- drag-to-pan
- mouse-wheel zoom
- + / - zoom controls
- reset control
- clickable city markers
- hover/tap tooltips with city name, title, and short summary
- city markers link directly to each city page

Note:
Marker positions were placed directly against the supplied map image.
If you later want any marker shifted a few pixels, edit the left/top percentages
on the relevant .city-marker in world.html.

The city copy was rewritten into the newer Sinners website style from the user's
current lore entries and recent corrections.
