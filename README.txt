Sinners Interactive World Map Pack V2
======================================

What's new in this version:
- Uses the newer larger placeholder map image.
- Added a decorative frame/border around the map.
- Moved the World page intro panel to a more integrated bottom-left position.
- Repositioned several markers so they stop covering city names as much as possible.
- Added map points for:
  - The Isle
  - The Calamity
- Added a hidden Great Tree Village hotspot:
  - nearly invisible by default
  - reveals a portal effect on hover/focus
  - links to a placeholder page
- Added a distance/ruler tool:
  - click the ↔ button to enable it
  - click two points OR click-and-drag
  - shows distance in USA-widths and approximate miles/km
- Added placeholder pages:
  - the-isle.html
  - the-calamity.html
  - great-tree-village.html

Calibration:
- Distance is based on the user's canon note that the top of Hilnem to the bottom of Palin
  is approximately 22 USA-widths.
- Conversion assumes 1 USA-width ≈ 2,800 miles.
